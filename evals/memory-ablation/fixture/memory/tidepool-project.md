Tidepool syncs a team's shared bookmark list to a static status page,
nightly and on demand. The owner's standing rules are in the project's
CLAUDE.md; this memory holds only what the code does not show.

Work lands on the main branch through a pull request the owner merges.
The owner reads the status page each morning and wants plain-words
answers with no code unless asked.
