**Status: in-force.**

## Ruling

The always-loaded route map names paths, not topics, and stays within 100
lines. It routes; it never duplicates the detailed content it indexes.

## Why

The always-loaded layer is the last increment on a context that is already
crowded with instructions the repository does not control. Every line pays
rent in diluted salience. The 100-line figure is a compliance budget to
measure against, not a validated threshold. A subagent inherits the
repository and nothing from the conversation, so the map must stand alone.
